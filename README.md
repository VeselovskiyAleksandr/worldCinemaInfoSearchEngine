# World Cinema Info Search Engine 

 * О проекте.                                                                                                                                                             
worldCinemaInfoSearchEngine - кроссплатформенный поисковый движок, предназначенный для полнотекстового поиска по документам.                                                           
Каждый документ в данном проекте содержит информацию об отдельном фильме: название, год выпуска, страна-производитель,
режисёр, участвующие актёры, краткое описание.                                                                                                                            
Поиск документов осуществляется по ключевым словам, вводимым пользователем.                                                                                                        
Проект реализован с использованием многопоточности, работой с файловой системой, парсингом JSON и сборкой с помощью CMake.

 * Технологии.                                                                                                                                                           
 Стэк: С++, Visual Studio, Cmake, STL, многопоточность, GoogleTest.                                                                                                                     
Поисковый движок использует стандарт С++ 17.                                                                                                                                    
Для сборки проекта необходима версия cMake 3.8 и выше.                                                                                                                                         
 В проекте используются:                                                                                                                                                              
  токенизация - разделения текстов на отдельные слова,                                                                                                                               
  ранжирование результатов — определение релевантности документов по запросу,                                                                                                          
  инвертированный индекс для эффективного поиска,                                                                                                                                
  многопоточный поиск — возможность параллельной обработки документов, что повышает производительность системы.                                                                       

  * Принцип                                                                                                                                                                       
  В проекте реализован принцип единственной ответственности (Single Responsibility Principle, SRP).                                                                                
Класс EngineStart отвечает за запуск поискового движка.                                                                                                                      
Класс ConverterJSON отвечает за работу со всеми JSON-файлами.                                                                                                                
Класс InvertedIndex отвечает за правильное заполнение коллекции уникальных слов.                                                                                        
Класс RequestsJSON отвечает за запросы, вводимые пользователем.                                                                                                              
Класс SearchServer отвечает за взаимодействие с сервером.                                                                                                                 
Класс AnswersJSON отвечает за вывод ответов пользователю.                                                                                                                            
 Версия и перечень документов находятся в файле config.JSON . Без него программа не работает.                                                                                                                                                                                                                                            
 Перечень параметров, с которыми работает программа, находятся в файле Configuration.h .                                                                                               
Он содержит перечень констант, использующихся в программе.                                                                                                                                                                                                                                                  
 Документы находятся в папке  resources.                                                                                                                                                                                                                                                                                                          
Запросы от пользователей поступают в файл requests.JSON и хранятся в нём.                                                                                                                                                                                                                                                                 
Ответы на запросы поступают в файл answers.JSON и выводятся на экран.                                                                                                            

 * Тестирование.                                                                                                                                                                      
 Для проверки правильности работы программы, в частности, для проверки правильности рассчёта абсолютной и
 относительной релевантности, используется система Google Test.                                                                                                           
 Юнит-тесты проверяют отдельные компоненты и функции движка, построение индекса, обработку запросов,
 ранжирование результатов.

 *Примеры.
 Пример работы программы показан в директории Examples. Для вывода примеров запросов перейдите в директорию Examples
 и выберите в качестве элемента запуска файл example.cpp .
 
  * Запуск.                                                                                                                                                               
Для работы с программой необходимо задать в качестве элемента запуска файлы из директории worldCinemaInfoSearchEngine/src .                                                                                                                                                                            
Для тестирования необходимо задать в качестве элемента запуска serverTest.cpp .

*Особенности.
  В файле Configuration.h задана нечитаемая длина слов до 3-х знаков включительно. Если в запросе содержаться слова с указанным
 количеством знаков или меньше, то запрос обрабатывается так, будто этих слов в запросе не содержится.

 * Примечание.                                                                                                                                                               
  Файлы resources, config.json, answers.json, requests.json автоматически копируются  из проекта
 в папку out/build/x64-Debug/worldCinemaInfoSearchEngine при первой сборке.                                                                                                       
 В случае, если программа выводит сообщение о том, что файлы не обнаружены, проверьте их нахождение по указанному пути.
 В случае отсутствия файлов в указанном месте, скопируйте их туда вручную.                                                                                                           
  При внесении новых документов или их изменении, проверьте, чтобы каждая строка в документе заканчивалась знаком пунктуации.
Это необходимо для корректной работы программы.

# Установка                                                                                                                                                                                                            
 Клонируйте репозиторий:
   bash
   git clone https://github.com/VeselovskiyAleksandr/worldCinemaInfoSearchEngine.git
   cd worldCinemaInfoSearchEngine                                                                                                                                                                                      
   Создайте директорию для сборки:
   bash
   mkdir build
   cd build                                                                                                                                                                                                            
   Запустите CMake:
   bash
   cmake ..                                                                                                                                                                                                            
   Соберите проект:
   bash
   cmake --build .                                                                                                                                                                                                     
   Запустите исполняемый файл:
   bash
   ./worldCinemaInfoSearchEngine
